# Quantile Regression with Python and statsmodels

Python scripts fitting quantile regression models with statsmodels for several predictors of sediment thickness, on Mariana Trench data. Reusable statistical-modelling example.

## Scripts

- `sm_quantile_regression_plate_carol_sedim_thick.py`
- `sm_quantile_regression_plate_maria_sedim_thick.py`
- `sm_quantile_regression_plate_pacif_sedim_thick.py`
- `sm_quantile_regression_plate_phill_sedim_thick.py`
- `sm_quantile_regression_profile_sedim_thick_e.py`
- `sm_quantile_regression_profile_sedim_thick_f.py`

## Data

- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `numpy`, `pandas`, `patsy`, `seaborn`, `statsmodels`.

```
pip install matplotlib numpy pandas patsy seaborn statsmodels
```
